# Feature docs

This directory holds one doc per delivered feature, named `<FE-id>-<slug>.md` (for example `FE-002-<slug>.md`). `tech-writer` writes each one when the feature ships, with the sections Overview, How to use, Reference, How it works, Operations, and Limitations and future work.

Write only what the code and tests show, and give the feature its status marker (`[built]` or `[planned: Pn]`). The backlog entry for a feature lives in `docs/backlog/epics/.../features/`; link the two docs to each other.
